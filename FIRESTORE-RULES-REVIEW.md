Связь с другим источником и ошибочный ID с неэкранированным двоеточием не блокируют несвязанную операцию. ## Найденная проблема

Первый расширенный запуск: **30 / 31**. Два конкурентных подтверждения одного платежа воспроизводимо приводили к `permission-denied` у проигравшей транзакции: победитель уже создал неизменяемые payments/links и расход. Повторная последовательная оплата работала, конкурентная проверка ранее отсутствовала.

Ошибка устранена в `budget-control/store.mjs`. Только для `pay` после `permission-denied` выполняется новая транзакция исключительно чтения. Результат «уже оплачен» возвращается, только если существует платёж с тем же `recurringId` и `dueDate`. Отсутствующая или чужая запись не превращает отказ в успех. Проверены конкурентные клиенты, отсутствие частичных записей при реальном отказе и запрет восстановления для анонимного/чужого пользователя.

Изменять правила для разрешения перезаписи истории не потребовалось. Ошибок в путях, владельце, идентификаторах `exists()` или допустимых схемах приложений не найдено; содержимое корневого `firestore.rules` оставлено без изменений.

## Готовность и повторение

Кандидат технически совместим с проверенными приложениями и готов к отдельной публикации **после выпуска исправления CloudStore и подтверждения настоящего входа владельца во всех пяти приложениях**, согласно порядку в `FIREBASE-AUDIT.md`. Эмулятор не подтверждает Google OAuth, физические Safari/PWA или наличие production composite indexes: эмулятор не воспроизводит требования таких индексов. Реальные финансовые данные в этой работе не использовались.

Запуск из `budget-control` с Node и Java в PATH:

```powershell
npm run test:rules
npm test
```

`test:rules` запускает только локальный Firestore Emulator с `--project demo-budget-control` и читает корневой `../firestore.rules`. Использовались Firebase CLI 14.27.0, Firebase SDK 12.19.0 и Java 21. Команда deploy не выполнялась.

Описание транзакций и ограничений проверки эмулятора: [транзакции Firestore](https://firebase.google.com/docs/firestore/manage-data/transactions), [отличия эмулятора от production](https://firebase.google.com/docs/emulator-suite/connect_firestore#how_the_cloud_firestore_emulator_differs_from_production).

## Ограничения, сохранённые в отчётах

- WebKit Windows сообщает об отменённых запросах WebChannel к эмулятору как `due to access control checks` при переходе/закрытии страницы. Эти сообщения сохранены отдельно в `transportWarnings`; все проверки данных, общих сессий, записей, обновления источников и выхода проходят. Это не основание считать физический Safari проверенным.
- `context.setOffline(true)` Playwright в WebKit вызывает внутреннюю ошибку движка на навигации. Поэтому успешный реальный офлайн подтверждён отдельной остановкой HTTP-сервера; результат искусственной эмуляции не выдан за успешный.
- WebKit не распознаёт viewport `interactive-widget` и игнорирует его. Есть отсутствующие старые локальные ресурсы с 404; ошибки выполняемого JavaScript в итоговых сценариях отсутствуют.
- Настоящий Google OAuth владельца, физические iPhone 14 Pro Max / iPad Pro 12,9, установленный iOS PWA и реальные Drive/Calendar API требуют проверки владельцем перед публикацией закрытых Rules. Тестовый Google popup эмулятора не подтверждает живой OAuth или поведение Safari/PWA.
- Redirect подготовлен, но выключен до корректной настройки same-origin auth helpers. GitHub Pages сейчас использует поддерживаемый popup.
